single-page CV/resume builder that runs entirely in your browser. Fill in a form, watch your CV update live, then print it or save it as a PDF. No backend, no sign-up, no data leaves your machine.
Live demo ← update this link after enabling GitHub Pages
Features
Live preview — your CV updates as you type
Add/remove multiple experience and education entries
Export straight to PDF using your browser's print dialog
Clean, single-file app — just HTML, CSS, and JavaScript, no build step
Usage
Open index.html in any browser (or visit the live demo link above)
Fill in your details on the left panel
Click Print / Save as PDF
In the print dialog, set destination to Save as PDF
